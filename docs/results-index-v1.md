# Results Index Schema v1

This document defines the repo-level aggregate artifact generated by:

- `scripts/collect-results.sh`
- `make collect-results`

Default output path:

- `docs/index.json`

## Top-level shape

```json
{
  "schema_version": "results-index/v1",
  "generated_at": "2026-04-04T10:00:00Z",
  "count": 2,
  "experiments": [
    {
      "id": "postgresql-vs-mongodb",
      "name": "PostgreSQL vs MongoDB",
      "category": "databases",
      "summary_file": "experiments/databases/postgresql-vs-mongodb/results/summary.json",
      "timestamp": "2026-04-04T09:00:00Z",
      "mode": "full",
      "result_count": 8,
      "summary": {}
    }
  ]
}
```

## Field rules

- `schema_version`: fixed string for the index wrapper.
- `generated_at`: index generation time in UTC ISO-8601.
- `count`: number of collected experiment summaries.
- `experiments`: one entry per discovered `results/summary.json`.

Each `experiments[]` item contains:

- lightweight index fields (`id`, `name`, `category`, `summary_file`, `timestamp`, `mode`, `result_count`)
- the full parsed `summary` object for downstream doc or dashboard generation

## Validation

- Only `results-summary/v1` inputs are accepted.
- Any incompatible summary file fails the collection step.
